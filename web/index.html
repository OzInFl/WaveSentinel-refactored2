WAVE SENTINEL

Sub-GHz · WiFi · Bluetooth Testing Tool

⚡ Web Installer

  1. Connect your WT32-SC01-PLUS to USB
  2. Click Install WaveSentinel below
  3. Select the serial port when prompted
  4. Wait for the flash to complete (~60 seconds)
⚠ Web Serial requires Chrome or Edge on desktop.
Mobile browsers and Firefox are not supported.

📡 Sub-GHz RF

CC1101-based capture, playback, scanning, and protocol analysis. Flipper .sub file compatible.

📶 WiFi Tools

Network scanner, beacon flood, deauth testing, promiscuous sniffer, and STA join.

🔌 BLE Tools

BLE advertisement spam (Apple, Android, Windows) and BLE device scanner.

🎧 RF Protocols

Princeton, KeeLoq, CAME, Nice FLO, GateTX, Linear, and more. Real-time analyzer.

🖼 Touch Display

3.5" 480x320 capacitive touchscreen with LVGL UI. No external tools needed.

💾 SD Card

Save and load Flipper .sub captures, presets, and configurations to microSD.

Hardware Specs

MCU ESP32-S3 @ 240 MHz
Display 3.5" ST7796 IPS
Touch FT5x06 Capacitive
RF Module CC1101 (300-928 MHz)
Memory 8 MB PSRAM + 16 MB Flash
Storage microSD (SPI)
Audio I2S DAC Output
Connectivity WiFi + BLE 5.0

Built with ESP-IDF + Arduino + LVGL + LovyanGFX

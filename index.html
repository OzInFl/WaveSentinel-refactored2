WAVE SENTINEL

Sub-GHz · WiFi · Bluetooth Testing Tool

An all-in-one RF security research platform built on the ESP32-S3. Capture, analyze, and replay Sub-GHz signals, crack rolling codes via the WaveKai cloud service, audit WiFi networks, transmit IR universal remote codes, and probe Bluetooth devices — all from a pocket-sized 3.5" touchscreen with no external tools required.

⚡ Install Firmware

  1. Connect your WT32-SC01-PLUS via USB-C
  2. Click Install WaveSentinel below
  3. Select the serial port when prompted
  4. Wait for the flash to complete (~60 seconds)
⚠ Web Serial requires Chrome or Edge on desktop.
Mobile browsers and Firefox are not supported.

📡 Sub-GHz RF (CC1101)

Full-spectrum Sub-GHz radio powered by the CC1101 transceiver. Capture, replay, scan, and decode RF signals across the 300–928 MHz band.

  • Read RAW — Dedicated CC1101 OOK async capture loop with IRAM ISR on GDO0, 4096-entry ring buffer, OOK 270 / OOK 650 / FSK 238 / FSK 476 preset chooser, live edge counter, fill bar, and pulsing "● CAPTURING" indicator. Saves Flipper-compatible RAW_Data .sub with the correct preset header
  • BinRAW Decoder — On-device generic bitstream decoder. Pick any saved .sub, hit DECODE: returns detected Te (µs), encoding (PWM / PPM / Manchester / NRZ), bit count, hex, and the first 80 bits in a popup
  • KeeLoq Clone — Capture any KeeLoq frame, decrypt with manufacturer key, increment counter, re-encrypt, and TX the next valid rolling code. Full Microchip HCS200/300/301 cipher (528 rounds, NLF 0x3A5C742E) implemented on the device
  • Frequency Analyzer — Flipper-style FFT spectrum sweep with live RSSI bars, snap-to-preset detection with hit counters, threshold slider, and Geiger-style audio feedback whose pitch tracks signal strength. Hot-swap freq from the dropdown without stopping the scan
  • Protocol Analyzer (Cloud) — Auto-identify across 130+ protocols against the WaveKai server in <500 ms
  • Flipper Player Screen — Hand-coded SD browser: folder + .sub file dropdowns auto-populate from real directories, PLAY / STOP / READ RAW / DECODE / KEELOQ CLONE actions, status line, dirty-write auto-save
  • CHAOS Tab — Tesla US (315 MHz) + Tesla EU (433.92 MHz) charge-port emulation, plus configurable Packet Generator for raw modulation testing
  • World Mode Toggle — NVS-persisted region unlock. US default (315 / 433.92 / 915 MHz) or WORLD (full CC1101 300–928 MHz) selectable from the Settings screen
  • Universal Remote — 35-button programmable remote (Numbers, Nav, Media). Assign any .sub file to any button. NVS-persisted last profile auto-loads on screen entry; auto-save on EDIT → DONE and on screen exit
  • RCSwitch Types A–D — DIP switch, rotary/sliding, Intertechno, and REV remote control transmit
  • Full CC1101 Config — Frequency, modulation (ASK/FSK/GFSK/MSK), bandwidth, deviation, data rate, TX power, sync mode, packet format
  • Flipper .sub I/O — Load, save, and play Flipper Zero sub files. RAW captures write with the correct FuriHalSubGhz preset header (Ook270 / Ook650 / 2FSKDev238 / 2FSKDev476)

🚀 Getting Started

  1. Get the hardware — WT32-SC01-PLUS board, CC1101 module, microSD card, and a USB-C data cable
  2. Wire the CC1101 — Connect MISO(11), MOSI(10), SCLK(14), CS(12), GDO0(13), VCC(3.3V), and GND
  3. Flash the firmware — Use the Install button above (Chrome/Edge), or build from source with pio run --target upload
  4. Insert SD card — FAT32 formatted, for saving captures and loading Flipper .sub files
  5. Power on & tap — The splash screen shows the firmware version. Tap anywhere to enter the main menu
